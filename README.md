# RePoint ♻️

Платформа за координация на разделно събиране и предаване на отпадъци.

RePoint ще свързва потребители с пунктове за събиране на отпадъци и кампании за рециклиране. Платформата ще позволява подаване на заявки за предаване, потвърждаване на реално предадените количества и проследяване на резултатите.

> Проектът е в начален етап. Описаните функционалности са планирани и предстои да бъдат реализирани.

## Планирани функционалности

- Регистрация, вход и управление на потребителски профил.
- Търсене на пунктове по материал, местоположение и работно време.
- Визуализиране на пунктовете върху карта.
- Създаване и проследяване на заявки за предаване на отпадъци.
- Операторско потвърждаване на посещения и реално предадени количества.
- Предотвратяване на двойно отчитане на предаванията.
- Управление на пунктове, материали и кампании.
- Отчети за потвърдените количества.
- Сигнали и известия.
- Адаптивен интерфейс за различни устройства.

## Планирани роли

| Роля | Основни възможности |
| --- | --- |
| Потребител | Търсене на пунктове, подаване на заявки и преглед на собствените предавания |
| Оператор | Обработка на заявки и потвърждаване на предадените количества в обслужваните пунктове |
| Организатор | Създаване и управление на кампании |
| Администратор | Управление на потребители, роли и основни данни в платформата |

## Технологии и архитектура

Съгласно заданието проектът ще използва:

- C# и ASP.NET Core — .NET 8 или по-нова версия.
- MS SQL Server.
- Entity Framework Core с Code First, миграции и начални данни.
- HTML5, CSS3 и JavaScript.
- Многослойна архитектура с отделни слоеве за потребителски интерфейс, бизнес логика и достъп до данни.
- Git и GitHub за управление на версиите.
- CI/CD за автоматизирано изграждане и проверки.

Конкретният подход за клиентската част ще бъде избран при проектирането.

## Тестване

Планирани са:

- Unit тестове с минимум 65% покритие на изпълнимите редове в бизнес логиката.
- Интеграционни тестове на основните процеси.
- Проверки на заявките, потвържденията и изчисляването на количествата.
- Проверки за защита срещу SQL Injection и XSS.
- Проверки на различни устройства и браузъри.
