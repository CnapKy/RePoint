# Статус, ограничения и история — RePoint Етап 1

Дата на работния пакет — 13.11.2026 г.

Тази страница описва състоянието на първоначалния архив. За локалните резултати от 14.11.2026 г. виж [E1_VERIFICATION.md](../E1_VERIFICATION.md).

## Подготвено
- Изследване на 3 сравними публични решения с проследими източници.
- Начална архитектура, ER схема и проектни решения.
- ASP.NET Core MVC + EF Core Code First изходен код и Razor UI.
- 9 домейн/потребителски модела, 5 MVC контролера, 8+ Razor изгледа и 5 ViewModels.
- Демонстрационни данни за материали и 2 изрично фиктивни пункта.
- Начални unit тестове, CI workflow, Docker Compose, документация и instructions.

## Не е потвърдено — проверява се на локалния компютър
- `dotnet restore`, `dotnet build`, `dotnet test` (в средата на изготвяне няма dotnet CLI).
- `docker compose up -d` и физическо създаване на БД (няма Docker/SQL Server).
- Създадена EF Core миграция, изпълнение на `dotnet ef database update`.
- Реална работоспособност на UI с база и Identity.
- Публичното GitHub хранилище https://github.com/CnapKy/RePoint вече съществува, но в него все още няма кода от настоящия архив; достъпът на консултанта и споделената документация не са потвърдени.
- 65% line coverage — финално изискване, не е удостоверено.
- Операторско потвърждение, 4 пълни роли, карта, отчети, управление на сигнали, известия и публичен URL — следващи етапи.

Публикуването и достъпът не бива да бъдат декларирани като извършени преди действителна проверка.
