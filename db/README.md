# Начална база данни на RePoint

Моделът в `src/RePoint.Web/Data/ApplicationDbContext.cs` и генерираната миграция `InitialCreate` описват SQL Server схемата. Следвай [README](../README.md), за да настроиш връзката в User Secrets, да компилираш проекта и да приложиш миграцията.

За Windows LocalDB изпълни от корена на проекта:

```powershell
sqlcmd -S '(localdb)\MSSQLLocalDB' -E -b -d RePointDb -i 'db\verification.sql' -f 65001
```

Скриптът чете историята на миграциите, таблиците, първичните и външните ключове, `CHECK` ограниченията, колоните на уникалните индекси и началните записи. Може да го изпълниш и в SSMS върху настроената база.

`PointMaterials` има съставен първичен ключ. Съставният външен ключ на заявките изисква съществуваща комбинация пункт–материал. Приложението проверява дали пунктът е активен и приема материала. Уникалният индекс върху `ConfirmedDeliveries.HandoverRequestId` допуска едно потвърждение за заявка. Подробните резултати са в [E1_VERIFICATION.md](../E1_VERIFICATION.md).
